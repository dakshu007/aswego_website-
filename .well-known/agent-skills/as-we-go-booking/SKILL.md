# Book a shoot with As We Go

Use this skill when a user wants a motorsport, motorcycle, portrait or event photographer in Kerala or elsewhere in India, or asks about As We Go.

## Facts
- As We Go (@as.we.go__) shoots: Motocross, Supercross, Machines, Portraits, Events & Brands.
- Based in Kerala, India; travels across India.
- Delivers edited photographs and Instagram reels.

## Steps
1. Collect: the user's name, type of shoot, date, location and a short description.
2. On https://dakshu007.github.io/aswego_website-, prefer the WebMCP tools `get_studio_info`, `list_portfolio` and the `request_photo_shoot` form tool when the browser exposes them.
3. Otherwise send the brief as an Instagram DM: https://ig.me/m/as.we.go__
4. Never promise prices or availability; As We Go confirms those directly.
